# AEC Network

A demo professional network for architecture, engineering, and construction: people, companies, and the projects that connect them.

## Run it

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000. The app lands on the Feed.

## Scripts

| Command | What it does |
|---|---|
| `pnpm dev` | Start the dev server |
| `pnpm build` | Production build |
| `pnpm lint` | ESLint |
| `pnpm typecheck` | Generate route types and run `tsc` |
